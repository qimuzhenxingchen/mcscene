# 菜单快照说明（fixtures）

本目录存放 **真实 MCP 返回的菜单快照**，供离线开发与测试使用。核心原则：**快照只用于开发调试，正式方案（result card / 卡片）的价格一律来自实时 `calculate-price` 重新核价**，本地引擎永远不自己定价。

## 快照清单

| 文件 | 内容 | 采集时间 | SIMULATED |
|---|---|---|---|
| `meals.1400242.dinein.20261018.json` | 麦当劳广州龙洞第二餐厅（storeCode 1400242，龙洞购物中心首层，距采集点 130m），到店自取菜单 | 2026-10-18 17:42 (GMT+8) | `false` |
| `meals.sample.json` | 脱敏样例，用于 CI / 单元测试，不含真实价格承诺 | — | — |

## 数据来源

- **价格与品项**：McDonald's China MCP `query-meals` 实时返回（storeCode 1400242, orderType 1 到店自取）
- **热量（kcal）**：`list-nutrition-foods` 实时返回（2026-10-18），按品项名对齐

## 营养数据覆盖率：21 / 29

29 个品项中 21 个带真实 kcal。**8 个为 `null`，是有意留空，不是缺数据**：

| 类型 | 品项 | 留空原因 |
|---|---|---|
| 歧义口味甜品 | 经典麦旋风 / 灰焰圆筒 / 派 / 新地 | `list-nutrition-foods` 返回多口味条目（如麦旋风有奥利奥/草莓等），无法唯一对齐，宁可留空也不猜 |
| 组合品 | "我就喜欢"鸡薯双全盒 / 人气经典随心配 / 精选超值随心配 | 组合内单品可替换，热量随内容变化，标注单一数值会误导 |
| 饮品 | 纯悦 | 营养列表中同名条目存在规格歧义（瓶装/小包装），无法对齐 |

## UNKNOWN 保护（引擎侧约定）

对 kcal 为 `null` 的品项，引擎**永不输出 0 或凭空编造**，统一回退为 `">=N kcal"`（N 为该方案内已确认品项的 kcal 之和），并在卡片上明确标注数据边界。对应实现见 `skill/scripts/mcsc_plan.py`，测试见 `skill/tests/test_engine.py`。

## 价格时效性

菜单价格会过期（促销、调价）。快照中的 `currentPrice` 已含当期促销，仅用于开发与演示；**任何面向用户的最终价格必须重新走 `query-meals` → `calculate-price` 链路**，并保留 MCP 返回的 originalPrice / discount 拆分以便溯源。
